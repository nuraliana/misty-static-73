One horror story in exactly two sentences, written for make.fun's Two-Sentence Horror bounty: fresh snow, a single set of footprints, and a narrator who never left the house.

## Give the tale a spin yourself

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

A two-sentence chill about fresh snow, one trail of footprints, and a teller who swears they never stepped outside — until the tracks turn out to be theirs.
Just launch the script with Python and it saves the finished story into the output folder.
